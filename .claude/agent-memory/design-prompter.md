# design-prompter 메모리

이 파일은 design-prompter가 작업 시작 시 읽고, 작업 종료 시 기록을 남기는 메모리/로그입니다.

## 작업 로그

### 2026-08-24 — ui-designer 브리프(단독): mercari 1차 톤 라운드 후속 — 병합 B(`43:2`) 대표화면 신규 제작 + A 확장(`48:2`)/C 확장(`51:2`) 대표화면 신규 제작, `36:35`/`36:2`(콜라주 저널링 B 대표화면) 미채택 라벨링
- **원본 요청**: 직전 라운드에서 brand-designer가 완성한 톤 프레임 3종(병합 B `43:2`/A 확장 `48:2`/C 확장 `51:2`)에 대응하는 대표화면을 ui-designer가 신규 제작. 병합 B는 기존 콜라주 저널링 B 대표화면(`36:35`/`36:2`)을 대체하는 성격이라 라벨링까지 포함. A 확장·C 확장은 기존 `20:3`/`23:3` 옆에 순수 추가(대체 아님). C 확장에는 브랜드 톤 프레임에서 정의된 레이아웃 전환·펄스 인디케이터·칩 외에, 이번에 새로 지정된 기능 디테일 2가지(2안 미선택 시 "다음 보기" 버튼 disabled, 기존 "1/2·2/2" 텍스트 인디케이터를 대체하지 않고 보완하는 점 스텝 인디케이터)가 추가로 요구됨.
- **핵심 판단**: (1) house rule 2-4번(반응형 원칙)과 유사하게, 병합 B 라벨링은 "라벨링 먼저 → 옆에 신규 제작"이 아니라 이번엔 신규 제작이 먼저 명시되고 라벨링은 완료 후 처리로 구성됐지만, 실제 실행 순서는 house rule 3-B번 3항의 "수정 시작 전에 먼저 라벨링" 원칙과 어긋나지 않도록(신규 프레임 제작과 기존 프레임 라벨링은 서로 다른 프레임이라 순서 상관없음을 확인 후) 브리프에 순서를 명확히 못박음: 신규 제작 완료 후 `36:35`/`36:2` 라벨링, 내용 무수정. (2) `20:3`/`23:3`은 순수 확장(대체 아님)이므로 원본 무변화 확인이 완료 기준에 필수 — A/B/C 세 계열의 "무엇을 대체하고 무엇을 보존하는지"가 서로 다른 패턴이라 헷갈리지 않도록 각 작업 블록에 개별 명시. (3) C 확장의 신규 기능 디테일(disabled 버튼, 점 인디케이터)은 브랜드 톤 프레임에 없던 새 요구사항이므로, "기존 확정 요소(1/2·2/2)를 대체하지 않고 보완"이라는 제약을 명확히 해 재해석으로 기존 인디케이터가 사라지는 사고를 예방. (4) 3개 신규 화면 모두 각 톤 프레임의 원본 5색 hex만 사용(design-systems 미투입 재확인)하도록 개별 명시.
- **구체화 포인트**: 병합 B의 구조 레이어(하드 그림자+아웃라인)/장식 레이어(washi tape·잉크스탬프·티켓스텁+소프트 그림자) 역할 분담을 SCR-002/003 실제 요소에 매핑 지시, A 확장의 정보 위계(콘텐츠>배지>콜아웃)를 크기·채도 대비로 구체화, C 확장의 disabled 버튼 처리를 저채도·저대비·클릭불가 시각 언어로 구체화, 완료 기준에 design-pl 보고 항목 5가지(신규 노드 ID, 라벨링 재조회 확인, 원본 무변화 근거, disabled/점 인디케이터 반영 자체점검, 5색 hex 준수 자체점검) 명시, 이번 라운드도 브랜드 톤 확정 전 보강이라 확정 스펙 문서(`docs/design/confirmed/`) 대상 아님 재확인.

### 2026-08-24 — brand-designer 브리프(단독): mercari 1차 톤 라운드 재작업 — 네오팝(`8:4`) 완전 제외 확인, `43:2` 미채택 라벨링, A확장(`48:2`) 컬러/포인트 기조로 Concept A(신규)/B(신규) 톤 프레임 제작
- **원본 요청**: 사용자가 "브랜드컨셉" 페이지(`8:2`)를 직접 열람해 두 가지를 지시: ① 네오팝 계보(`8:4`, 화면 `21:2`/`21:3`)는 완전히 제외 — 삭제하지 않고 그대로 두되 앞으로 참고 대상 아님(brand-designer 액션 없음). ② "Concept A — 확장"(`48:2`)의 컬러 느낌과 포인트를 기조로 A안·B안을 다시 만듦. brand-designer 실행 항목은 3가지: (1) `43:2`(브루탈 콜라주 병합본) 미채택 라벨링, (2) `48:2` 재실측, (3) 같은 컬러/포인트 언어를 공유하는 Concept A(신규)/B(신규) 톤 프레임 2개 신규 제작 — A는 `48:2`의 정제(elevate), B는 같은 팔레트를 공유하되 톤 프레임 표현 수준(타이포 웨이트, 배지 스케일, 콜아웃 강조, 카드 강조 뉘앙스)에서만 A와 다른 인상.
- **핵심 판단**: (1) 컬러 출처를 `48:2` 고정값 하나로 엄격히 제한 — 다른 계보(`8:4`/`28:2`/`43:2`)나 외부 레퍼런스의 색을 섞지 않도록 별도 절("컬러 출처 원칙")로 분리하고 완료 기준에 자체 점검 항목으로 명시. (2) B(신규)의 차별화 범위를 "톤 프레임 수준"으로 명확히 제한 — 실제 레이아웃 구조 차별화는 다음 단계(ui-designer 대표화면)의 몫이라는 사용자 제약을 그대로 보존해, brand-designer가 성급하게 레이아웃 골격까지 다르게 만들지 않도록 못박음. (3) 이번 라운드는 지정된 프레임 2개+라벨링 1건의 중간 보강이라 "시안 3개 확정 전 후속 금지" 문구를 임의로 추가하지 않음(과거 동일 패턴 라운드와 동일하게 처리, PL이 지시하지 않은 게이트를 스스로 만들지 않는다는 원칙 준수). (4) `48:2` 값을 메모리 재사용이 아니라 반드시 실측하도록 명시(참고값은 메인 세션 전달치를 표로 제공하되 "실측값 우선" 명시).
- **구체화 포인트**: 완료 기준에 `43:2` 라벨 텍스트 확인, A/B 신규 nodeId, 적용 색상 hex 전체 목록(ui-designer 브리프 인용 근거), A/B 표현적 구분 설명, 컬러 출처 자체 점검, 나머지 프레임 무변화 확인을 6개 항목으로 명시. C 계보(`8:5`/`51:2`)·A 원본/확장 자체(`8:3`/`48:2`)·이미 미채택인 `8:4`/`28:2`는 절대 불가침으로 재확인. 이번 라운드도 확정 게이트가 아니므로 `docs/design/confirmed/`·`brand-guide.md` 갱신 대상 아님.

### 2026-08-24 — ui-designer 브리프(단독): mercari 1차 톤 라운드 최종 국면 — Concept A(신규 `72:2`)/B(신규 `72:69`) × 템플릿1(참고 A안 레이아웃)/템플릿2(참고 C안 레이아웃) 대표화면 4개 신규 제작 + `61:28`(브루탈 콜라주 대표화면) 미채택 라벨링

### 2026-08-24 — ui-designer 브리프(단독): mercari 1차 시안 4개 대표화면(`75:2`/`79:2`/`85:2`/`86:2`) 완성도 폴리싱 — 실사 이미지 적용 후 디테일 다듬기
