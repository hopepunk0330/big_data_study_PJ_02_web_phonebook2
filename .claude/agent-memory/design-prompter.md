# design-prompter 메모리

이 파일은 design-prompter가 작업 시작 시 읽고, 작업 종료 시 기록을 남기는 메모리/로그입니다.

## 작업 로그

### 2026-08-24 — brand-designer 브리프(단독): mercari 1차 톤 라운드 재작업 — B 계보 병합(네오팝+콜라주 저널링→브루탈 콜라주 신규) + A/C 확장 프레임 추가
- **원본 요청**: 사용자가 페이지 "브랜드컨셉"(`8:2`)의 현재 상태(A=`8:3` 미니멀 신뢰형/네오팝B=`8:4` 이미 미채택/콜라주저널링B=`28:2` 아직 미라벨/C=`8:5` 벤토 다크)를 보고 두 가지를 동시에 요청: ① 네오팝(`8:4`, 굵은 잉크 아웃라인+하드 오프셋 그림자+플랫 컨페티)과 콜라주 저널링(`28:2`, washi tape+티켓스텁 대시보더+잉크스탬프+소프트 디퓨즈 그림자)을 팔레트 고정(코랄/옐로/바이올렛/크림/잉크 5개 hex)한 채 스타일 언어만 병합한 완전히 새로운 Concept B 톤 프레임을 `8:2`에 신규 제작 → 병합 후 `28:2`에 `❌ 미채택 —` 라벨만 붙임(내용 무수정, `8:4`는 그대로 둠). ② A(`8:3`)·C(`8:5`)는 절대 무수정, 그 옆에 레이아웃/정보위계를 한 단계 더 발전시킨 "확장" 톤 프레임을 각각 신규 제작(컬러 아이덴티티는 유지, A=블루 미니멀+절제된 배지/신뢰 콜아웃 박스 인사이트, C=다크히어로→라이트 바텀시트 전환+펄스 인디케이터+칩 인터랙션 디테일 인사이트). 다른 프로젝트 폴더의 원본 레퍼런스 이미지(읽기 전용) 열람은 선택.
- **핵심 판단**: (1) 이번 라운드는 신규 3원 시안 세트를 만드는 게 아니라 기존 A/B/C 트리오에 대한 지정된 개수(병합 B 1개 + A 확장 1개 + C 확장 1개)의 보강 제작이라, "시안 3개 확정 전까지 후속 금지" 문구는 design-pl로부터 그렇게 지시받지 않아 임의로 새로 추가하지 않음(스스로 시안 여부를 재판단하지 않는다는 원칙 준수). (2) house rule 2번 "미채택 시안 원본 보존"을 그대로 적용해 `28:2` 라벨링은 이름만 변경(내용 무수정), `8:4`는 이미 라벨링된 상태이므로 이번엔 손대지 않음을 재확인. (3) "장난스럽지만 손으로 꾸민 듯한 브루탈 콜라주"라는 추상적 톤 요구를, "하드 그림자+두꺼운 아웃라인=구조를 잡는 베이스 레이어" vs "washi tape/잉크스탬프/티켓스텁=그 위에 얹는 장식 레이어(소프트 그림자 전용)"라는 레이어 역할 분담 원칙으로 구체화해 "한 화면에 두 그림자 스타일이 공존해도 어수선하지 않고 의도적으로 보이게" 하는 실행 기준을 제시. (4) A/C 확장의 참고 인사이트(배지·콜아웃/펄스·칩)는 컬러를 베끼지 않고 우리 팔레트로 치환해서 반영하도록 명시(다른 프로젝트 레퍼런스 열람이 브랜드 컬러 오염으로 번지지 않게 하는 안전장치).
- **구체화 포인트**: 새 프레임 3개 모두 `8:2` 페이지 안, 기존 프레임과 겹치지 않는 위치 배치 + 네이밍에 "Concept B — 브루탈 콜라주"/"Concept A — 확장"/"Concept C — 확장" 계열임을 명시(최종 워딩은 brand-designer 재량), 완료 기준에 design-pl 보고 항목(신규 프레임 3개 노드 ID, `28:2` 라벨 텍스트 변경 실측 확인, `8:3`/`8:4`/`8:5` 무변화 근거) 명시, 이번 라운드는 브랜드 톤 확정 전 중간 보강이라 `docs/design/confirmed/`·`docs/design/brand-guide.md` 갱신 대상 아님을 재확인.
