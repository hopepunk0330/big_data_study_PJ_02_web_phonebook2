- **신규 패턴(66차)**: 워커 에이전트 파일을 "전면 재작성"할 때, 그 워커를 호출하는 오케스트레이션 스킬(`SKILL.md`)이 "반드시 포함된다"류의 자체 실행 지시를 갖고 있으면, 에이전트 파일의 판단 기준 변경과 별개로 SKILL.md의 그 실행 지시 목록도 함께 대조해야 한다 — "판단 기준은 에이전트 파일이 정본"이라는 disclaimer는 SKILL 자신이 내리는 구체적 실행 지시까지는 면제해주지 않는다.
- **신규 패턴(66차)**: 같은 파일 안에 문단을 새로 삽입하면(줄 수 증가), 그 파일의 특정 줄 번호를 인용하는 다른 문서(`reset-checklist.md` C-3 등)가 자동으로 stale해질 수 있다 — 문단 삽입형 편집일수록 발생 확률이 높다(교체형 편집보다).
