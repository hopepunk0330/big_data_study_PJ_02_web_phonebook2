# brand-designer 메모리

이 파일은 brand-designer의 최근 작업 로그(휘발성, 5개 캡)만 남깁니다. **브랜드 결정사항 자체(현재 확정 상태)는 여기 없습니다 — `docs/design/brand-guide.md`가 그 소스 오브 트루스입니다.** 작업 시작 시 이 로그가 아니라 그 문서를 먼저 읽으세요.

## 작업 로그

### 2026-07-29 (1차 시도, 이후 재작업됨) — "레이아웃만 다르고 성격은 같다" 진단 + 퍼스낼리티 3안 정의
- 사용자가 New Concept 1/2/3이 "1안과 3안이 왜 같냐"고 지적 → `get_metadata`로 10개 섹션 구조 대조, 레이아웃 패턴만 다르고 퍼스낼리티는 실질 하나였음을 확인.
- **문제점(사용자 재지적)**: 이때 페르소나 3개(슬로우 리추얼/랩노트/골드아워)의 근거로 무드보드를 다시 보지 않고 **예전에 요약해둔 "7개 레이아웃 패턴" 메모**를 재사용함 — 레퍼런스 재관찰 원칙 위반. 아래 항목에서 재작업.

### 2026-07-29 (재작업) — 무드보드(`49:38`) 직접 재관찰로 퍼스낼리티 3안 재정의(근거 있는 버전)
- 1차 시도의 문제(요약 메모 재사용)를 수정하기 위해 `49:38`을 다시 직접 관찰: 전체 개관(`maxDimension:2200`)으로 36개 프레임 구도 확인 후, 클러스터 후보별 대표 이미지 6장(`49:8`/`49:30`/`49:2`/`49:19`/`49:20`/`49:22`/`49:18`)을 개별 확대(`maxDimension 600~900`)해서 색상·타이포·톤 실측.
- **관찰 결과**: 34장이 레이아웃 패턴이 아니라 실제로 3개의 구분되는 브랜드 퍼스낼리티 축을 보여줌 — (1) 임상/성분 정보형("랩노트", 이후 사용자가 완전 반려), (2) 대담한 확신형 에디토리얼("스포트라이트", 확정 대기 유지), (3) 다정한 데일리 리추얼("슬로우 리추얼", 확정 대기 유지).
- Figma는 읽기 전용(get_screenshot/get_metadata)만 사용, 쓰기 없음. design-pl에게 근거(노드ID+구체적 위치·특징) 포함 3안 보고, 확정/정식화는 진행하지 않음.

### 2026-07-29 (2차 재작업) — "랩노트" 완전 폐기, 신규 제3 페르소나 "빅토리 팝" 정의(트렌드 포커스 재관찰)
- 배경: 사용자가 "랩노트"(임상/화이트 톤)를 레퍼런스 부적합 + 컨셉 자체 비선호로 완전 반려, 추가로 "미채택 시안들처럼 올드해 보이면 안 된다"는 조건 부여. New Concept 2(`171:2`, 랩노트) 자리에 들어갈 완전히 새로운 페르소나가 필요.
- 무드보드(`49:38`)를 다시 직접 재관찰(전체 개관 + 미배정 이미지 6장 `49:8`/`49:18`/`49:21`/`49:24`/`49:25`/`49:33` 개별 확대, `maxDimension 900`, base64) — 이번엔 "최근 트렌드/올드하지 않음"에 초점.
- **발견**: 34장 중 상당수가 **채도 있는 솔리드 컬러블록(네이비/옐로우/핑크/민트) + 원형 배지·스탬프 그래픽(수상 스탬프, 퍼센트 통계 배지, 할인 배지) + 초대형 숫자/스탯 타이포 + 다이컷(퍼즐피스)·대각선 스플릿 레이아웃 + 손그림 낙서/브러시 커서브 악센트(딱 한 단어만)**라는 일관된 "그래픽팝/네오팝 프로모션" 트렌드 축을 이룸(1안 슬로우 리추얼·3안 스포트라이트 어느 쪽에도 안 쓰인 근거들).
- **신규 페르소나 정의**: **"빅토리 팝(Victory Pop)"** — "증명하고 자랑하는, 승리를 선언하는 확신형"(스포트라이트의 "차분한 에디토리얼 확신"과 다른, 배지·숫자로 성과를 당당히 전시하는 축제형 확신). 팔레트는 기존 확정 팔레트(크림/탄/베이지/차콜/골드/화이트/블랙)를 그대로 쓰되 채도 대비를 극대화(차콜 vs 탄/베이지를 하드엣지 대각선/그리드 블록으로 분할, 골드는 배지 링·스탬프·초대형 스탯 숫자에만 좁게 사용해 "럭셔리 포일"이 아니라 "메달"처럼 읽히게 함), 레이아웃은 밴드분리형·풀블리드 오버레이형과 다른 **그리드/대각선 블록 분할형**(블록 접합부에 원형 배지가 걸쳐 앵커링됨). 타이포는 볼드 지오메트릭 산세리프 헤드라인 + 헤드라인보다 큰 초대형 스탯 숫자 + 브러시 커서브는 한 단어에만 제한.
- Figma 쓰기 없음(읽기 전용 관찰만), 새 프레임 생성하지 않음. design-pl에게 근거(노드ID `49:8`/`49:18`/`49:21`/`49:24`/`49:25`/`49:33` + 위치·특징) 포함 보고, 확정/정식화는 design-pl·사용자 몫으로 남김.

### 2026-07-29 (3차) — 3개 시안 장식 오브제 스타일 방향 정의(graphic-designer 투입용, 이번 프로젝트 최초 오브제 방향 신설)
- 배경: New Concept 1/2/3(Slow Ritual `162:2`/Victory Pop `201:5`/Spotlight `176:2`) 전부 지금까지 기본 도형(RECTANGLE/ELLIPSE/LINE)만으로 장식 — graphic-designer 투입 빈도 강화 지시에 따라, 이 프로젝트에서 아직 한 번도 정의된 적 없는 오브제 스타일 방향을 brand-designer 몫으로 신규 정의.
- 3개 시안 핵심 노드(S1 BG, 배지, 웨지, 스플릿 패널 등)의 fill/stroke를 read-only `use_figma` 스크립트로 실측(추측·메모리 재사용 금지): Slow Ritual — cream `#e4d6c3`, warm pill bg `#ede6dc` + tan/gold border `#b8935b`, ink `#2b2621`, Noto Serif KR 확인. Victory Pop — charcoal `#1f1b17` vs beige triad(`#e4d6c3`/`#ede6dc`/`#f0e6d8`), 배지 원 채움 진한 ink `#2b2621` + gold stroke 3px `#b8935b`. Spotlight — charcoal `#1f1b17` + burst 배지 gold `#d4a857`(빅토리 팝의 muted gold `#b8935b`보다 쨍한 별도 톤으로 확인) + 대각선 tan wash `#b8935b`@14% 오퍼시티, 배지 라벨 폰트 Gaegu Bold(손글씨 커브).
- 3개 시안 각각 라인 굵기/채움 방식/색상 지정 + 오브제 5개 항목(예: Slow Ritual — 라인아트 잎사귀 클러스터·물방울 클러스터·촛불·초승달·손글씨 언더라인; Victory Pop — 메달 리본 배지·스탬프 인증 도장·각진 컨페티 조각·체크마크 배지·화살표/트로피 실루엣; Spotlight — 골드 스파크 별·방사형 광선 다발·손그림 마크업 서클·손그림 화살표·각주 별표)와 배치 섹션(1~10) 참고를 design-pl에 보고. Figma에는 아무것도 새로 그리지 않음(읽기 전용 관찰만), design-qa·정식화 진행 안 함.

### 2026-07-29 (4차) — 사용자 지적("1안·2안 컬러톤 같다") 재검증 + Victory Pop 팔레트 계열 자체를 네이비로 교체
- 배경: 3차에서 오브제 방향을 정의했지만 실은 팔레트 자체가 문제였음 — 3개 시안 `use_figma` read-only로 재실측한 결과, Victory Pop(`201:5`)의 dark block `#1f1b17`이 Spotlight(`176:2`)의 dark bg `#1f1b17`/`#2b2621`와 **완전 동일 hex**, Victory Pop의 light panel(`#e4d6c3`/`#ede6dc`/`#f0e6d8`)이 Slow Ritual(`162:2`)의 배경(`#e4d6c3`/`#ede6dc`/`#f3e4ce`)과 **거의 동일 계열**이라 3안 모두가 사실상 "크림/탄 + 차콜" 두 색군을 돌려썼다는 게 실측으로 확인됨.
- **결정**: Victory Pop의 배경/블록/배지 색만 완전히 새 계열(네이비)로 교체 — Dark Navy `#1B2A4A`(구 charcoal `#1f1b17` 대체) / Ink Navy `#12213D`(구 `#2b2621` 배지 채움 대체) / Pale Ice-blue `#E6EBF3`(구 `#ede6dc`/`#f0e6d8` 대체) / Deeper Ice-blue `#D7E0EE`(구 `#e4d6c3` 대체). 헤드라인 강조 골드 `#B8935B`는 copy.md 고정값이라 불변, 배지 스트로크·CTA·메달 골드도 동일 값 유지(네이비와 짝지어 "훈장/졸업 코드/증서" 관용 색조합을 형성해 "증명하고 자랑하는" 퍼스낼리티에 색채심리학적으로 더 맞음). 근거로 2차 재작업 때 이미 무드보드(`49:38`)에서 "네이비/옐로우/핑크/민트 컬러블록"이 관찰됐던 것도 재확인(당시 미채택이었던 네이비를 이번에 채택).
- 오브제 색상 지정 갱신: 메달 리본배지=gold 스트로크(불변)+navy 채움, 스탬프=navy 잉크, 컨페티=navy+ice-blue 교차(gold는 소량 반짝이는 조각만), 체크마크 배지=navy 원+gold 체크, 화살표/트로피=navy 실루엣+gold 하이라이트.
- Figma 쓰기 없음(read-only 재실측만), 정식화·design-qa 진행 안 함. design-pl에게 3안 팔레트 hex 비교표 + Victory Pop 신규 확정 팔레트 보고.
