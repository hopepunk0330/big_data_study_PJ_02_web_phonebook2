# copywriter 메모리

이 파일은 copywriter가 작업 시작 시 읽고, 작업 종료 시 기록을 남기는 메모리/로그입니다.

## 작업 로그

### 2026-07-26 — AI 생성 이미지 콘텐츠 카피 기능 검증 테스트 (가상 제품, 프로젝트 무관)
- 요청: service-planner 스토리라인 브리프(10섹션, 천연 성분 수분 크림 상세페이지)를 받아 섹션별 실카피 작성.
- 범위: 이 프로젝트(연락처 관리 웹앱)와 무관한 가상 테스트 — 문서 반영/canonical 갱신 없음. 참고용 기록만 남김.
- 톤 판단: brand-guide.md 부재 + 프로젝트 무관 테스트라 자체 판단 — "안심되고 담백한, 과장하지 않는" 톤 지시를 따름. 단정적 보증 표현("100% 무자극")과 근거 없는 기간·수치("2주 만에") 금지 제약을 전 섹션에 일관 적용.
- 제품명 미지정 상태라 [제품명] 플레이스홀더 사용 — 실제 적용 시 치환 필요.
- 산출물: 10섹션 각 헤드라인/본문/CTA (아래 "다음 작업자 참고" 참조, 본문에는 전체 텍스트 미보관 — 응답 로그에서 확인).

## 다음 작업자 참고
- AI 생성 이미지 콘텐츠(상세페이지) 요청 시: service-planner의 스토리라인 구조(섹션 수·순서)는 그대로 따르고, 카피만 채워 넣는 역할 경계를 지켰음 — 향후 유사 요청도 동일 패턴 유지.
- "과장 금지" 계열 제약(무자극 단정, 임의 기간/수치)은 뷰티·헬스 카테고리 상세페이지에서 반복될 가능성 높음 — 기본값으로 유의.
